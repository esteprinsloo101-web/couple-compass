# Couple Compass

Faceless South African **relationship self-help** tools for consenting adults (18+).

Free static demo + paid Gumroad pack (**R149**).

## Hard safety
- **Not** couples therapy, counselling, mediation, or clinical advice  
- **Not** for active domestic violence — if unsafe: **112** · SAPS **10111** · GBV **0800 428 428** / **\*120\*7867#** · [findahelpline.com](https://findahelpline.com)  
- **18+ only** · No AI therapist chat · Scenario cards + exercises only  

## Demo app
Open `index.html` (or GitHub Pages once deployed).

Modes: Daily check-in · Conflict repair · Appreciation · Listening · Values talk  
Relationship pulse (1–5) stored in `localStorage` only.
