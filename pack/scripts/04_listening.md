# Script — Listening exercise (speaker / listener)

**Not therapy.** Adults 18+ only. Start with a **low-stakes** topic.

## Roles
- **Speaker:** 3 minutes uninterrupted.  
- **Listener:** summarise only — no fixing, no rebuttal yet.  
- Speaker rates accuracy 1–5 → clarify → **swap**.

## Listener lines
> “What I’m hearing is ___. Is that close?”  
> “Say more about the part where you felt ___.”  
> “I’m holding advice for now — I want to get you first.”

## After both turns (optional)
One joint question: “What’s one small next step we both agree on?”

## Pause if
Mocking, controlling interruption, or the topic involves abuse → stop. Safety: 112 · GBV 0800 428 428.
