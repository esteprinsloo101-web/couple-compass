# Couple Compass — Relationship Tools Pack

Faceless South African relationship self-help pack for adults (18+).

**Price:** R149 · Free companion demo web app

## Contents
- `DISCLAIMER.md` — **read first** (hard safety fence)
- `scripts/` — printable conversation scripts for each mode
- `worksheets/` — HTML worksheets (open in browser → Print / Save as PDF)

## Modes covered
1. Daily check-in  
2. Conflict repair  
3. Appreciation  
4. Listening exercise  
5. Values talk  

## How to use
1. Read `DISCLAIMER.md`.  
2. Pick one mode.  
3. Use the matching script + worksheet together.  
4. Keep sessions short (5–20 minutes). Consent from both adults.
